Start your Qwen llama.cpp server for local evaluation. Use 9B Q4_K_M for quality, or 4B Q4_K_M for a shorter report wait.

Save these settings in the .env file in this installation:

INTERVIEW_SIMULATOR_GGUF=models/primary/Qwen3.5-9B-Q4_K_M.gguf
INTERVIEW_SIMULATOR_WHISPER_MODEL=models/whisper/ggml-small.bin
INTERVIEW_SIMULATOR_TTS_BACKEND=auto

Then open a terminal in this project folder and run:

uv run interview-simulator local-server

The server can start without a local model. Choose a cloud provider to use cloud text instead.

For cloud models through your local Ollama server, run ollama signin first. A key entered here does not sign in the daemon. Direct official cloud uses your API key.

Local keys are optional. Official cloud requires a key. A local daemon can also send text to a cloud model; review model locality before starting.

The key is sent to your local server once. It is never saved in browser storage or included in reports.
